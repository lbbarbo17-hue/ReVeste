# ReVeste — Brechó Digital

> **Plataforma Web de Brechó Digital para Compra, Venda e Consumo Consciente de Roupas de Segunda Mão**  
> *Projeto Integrador II*

---

## 📌 Sobre o Projeto

O **ReVeste** é uma solução web integrada voltada ao comércio de roupas usadas e sustentáveis, conectando quem deseja desapegar a consumidores que valorizam moda acessível, exclusiva e consciente.

A plataforma se diferencia por tratar peças de brechó como itens físicos de **SKU único**, com mecanismos de controle de concorrência que evitam a venda duplicada (*overselling*), além de dashboards analíticos de impacto socioambiental (peças reaproveitadas).
